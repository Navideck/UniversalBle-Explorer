Release Notes — UniversalBle Explorer 1.2.0

GATT Server: Create, edit, and manage GATT server profiles, run a peripheral server with advertising, add or remove services at runtime, and import or export profiles as JSON.

Device Fingerprint: Capture a complete device fingerprint in one tap — 60 seconds of consolidated advertisements, discovered services, all readable characteristic values, and a rolling-ID check after reconnecting. Copy the full report, or stop the capture at any time.

Logs: Add custom log entries, clear individual entries, auto-scroll to newest entries with a persisted toggle, see the characteristic UUID on read/write/error entries, and copy advertisements with an optional RSSI column.

Scanning: Filter characteristics by UUID text (case- and hyphen-insensitive) and choose the new Auto queue type from the drawer.

UI: The app is now UniversalBle Explorer with a refreshed icon, plus fixes for search-field, card-header, per-log clear-button and Write-button alignment. Empty services show a clear placeholder, duplicate service keys are gone, and BLE errors no longer go unhandled.

Platform: Migrated to universal_ble 3.0, upgraded file_picker to 12.0.0, and removed CocoaPods from the iOS and macOS projects.
